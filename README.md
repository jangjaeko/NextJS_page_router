# Next.js Page Router Study Archive

This project is a learning archive for studying the **Next.js Page Router** architecture and its core routing patterns.

Each commit represents a focused implementation or experiment related to Page Router features such as routing behavior, data fetching methods, dynamic routes, and rendering strategies.  
By reviewing the commit history, you can easily revisit specific topics and understand how Page Router works in real-world scenarios.

## Purpose

- Practice and document Next.js Page Router fundamentals
- Build hands-on examples using the traditional `pages` directory structure
- Track learning progress through commit-based history
- Create a reference project for maintaining and migrating legacy Page Router applications

## How to Use This Repository

- Review commit history to study individual routing and data-fetching patterns
- Checkout specific commits to isolate and test features
- Use this project as a reference when working with existing Page Router codebases

## Covered Topics (Examples)

- File-based routing using the `pages` directory
- Dynamic routes and catch-all routes
- Query parameters and router usage (`useRouter`)
- Data fetching methods (`getStaticProps`, `getServerSideProps`, `getStaticPaths`)
- Client-side navigation with `next/link` and `next/router`
- API routes
- Error handling and custom error pages
- Incremental Static Regeneration (ISR)
